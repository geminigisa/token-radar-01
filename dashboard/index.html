Token Launch Radar

Protocols that record no token, ranked by the implied value of a token they may one day issue. The value is this radar's own claim, derived only from the sealed snapshot — never a prediction of whether or when a token is issued.

How the implied value is computed

implied value = TVL × category multiple × growth factor × maturity factor

  • Category multiple. The median market-cap / TVL ratio of token-recorded protocols in the same category, shrunk toward the overall median (n / (n + 10) weight); categories with fewer than 5 priced peers use the overall median. Computed from this snapshot at run time, never hardcoded.
  • Growth factor. 1 + clamp(7-day TVL change, −30, +30) / 100 × 0.5. A change beyond ±300% or a missing value counts as 0 and is flagged — a one-week move that large is a reporting artefact, not growth.
  • Maturity factor. 0.90 + 0.10 × min(days tracked, 1095) / 1095; unknown age counts as 0.95. Days are counted from the snapshot's frozen date, and shown as “days tracked”, not “days awaiting a token”.
  • What it is not. This is an implied market cap under comparable valuations, not a launch probability, not a future FDV, and not an expected airdrop payout. “Records no token” means the snapshot carries no token for the protocol — it is not proof that none exists.
